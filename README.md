# Sprint_6

Тестирвоание страницы https://qa-scooter.education-services.ru/

## Вопросы и ответы на главной
Файл: `tests/test_main_page.py`
Параметризованный тест `test_question` проходит по всем 8 вопросам.
- Скроллит до блока с вопросами.
- Кликает по вопросу.
- Сравнивает текст раскрывшегося ответа с ожидаемым.

## Оформление заказа
Файл: `tests/test_order_page.py`

Два теста проверяют два разных входа в форму заказа:

- `test_header_order_create` | кнопка «Заказать» в шапке страницы 
- `test_bottom_order_create` | кнопка «Заказать» в футере страницы 

Каждый тест проходит полный пользовательский путь:
- Открывает главную и закрывает куки-баннер.
- Переходит в форму заказа.
- Заполняет персональные данные.
- Выбирает станцию метро.
- Переходит на страницу «Про аренду».
- Выбирает дату, срок аренды, цвет и комментарий.
- Подтверждает заказ в двух попапах.
- Проверяет экран «Заказ оформлен».
- Переходит на страницу статуса и убеждается, что заказ создан.
